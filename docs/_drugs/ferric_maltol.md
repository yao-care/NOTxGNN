# Ferric Maltol：從缺鐵性貧血到 Plummer-Vinson 症候群

## 一句話總結

Ferric maltol（三價鐵-麥芽酚錯合物）為口服鐵劑，核准機轉為治療缺鐵性貧血。
TxGNN 模型預測其可能對 **Plummer-Vinson 症候群** 有效，
但目前**無任何臨床試驗**與**無任何文獻**支持此方向，證據等級為 L5（僅模型預測）。

## 為什麼這個預測合理？

目前尚無詳細作用機轉（MOA）資料。根據現有資訊，ferric maltol 是口服三價鐵鹽（麥芽酚螯合鐵），
核准機轉為補充鐵質以治療缺鐵性貧血，其療效已在缺鐵性貧血族群中獲得證實。

Plummer-Vinson syndrome（又稱 Paterson-Brown-Kelly syndrome）之核心病理即為長期缺鐵性貧血合併食道蹼與吞嚥困難，
鐵劑補充本為此症候群現行標準治療之一環。因此 ferric maltol 補鐵的既有機轉，
在機轉層面與此適應症有高度生物學合理性——但這屬於既有機轉在特定症候群的延伸推論，
**並非基於任何直接針對該適應症之臨床試驗或文獻證據**，仍屬未經驗證的研究假說。
