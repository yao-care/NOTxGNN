## Enzalutamid: androgenreseptorhemmer → Prostataleiomyom (prostate leiomyoma)
{: .text-alpha }

## Oppsummering

Enzalutamid er en hormonell, målrettet kreftbehandling som blokkerer androgenreseptoren.
TxGNN-modellen forutsier at legemidlet kan ha effekt ved **prostataleiomyom (prostate leiomyoma)**.
Det er **ingen kliniske studier** og **ingen publikasjoner** som direkte undersøker denne sykdommen i dataene som er sammenstilt for denne rapporten. Prediksjonen er derfor kun modellbasert.

## Hvorfor kan denne prediksjonen være rimelig?

Data om virkningsmekanisme (MOA) er foreløpig ikke tilgjengelig i de sammenstilte dataene. Enzalutamid tilhører klassen androgenreseptorantagonister, og effekten av denne klassen i androgenavhengig vev er kjent. Prostata er et androgenfølsomt vev, så det er i prinsippet plausibelt at blokkering av androgenreseptoren kan påvirke svulster som oppstår der.

Leiomyomer er imidlertid mesenkymale glattmuskelsvulster, og det er ikke påvist at de er avhengige av androgenreseptorsignalering. Prediksjonen har høy modellscore, men mangler støtte fra kliniske data eller litteratur. Den bør derfor sees som en hypotese som må underbygges.

## Konklusjon og neste steg

Prediksjonen bygger kun på modellscore (0,9957) uten kliniske studier eller litteratur som direkte undersøker prostataleiomyom. Det finnes heller ingen påvist androgenavhengighet for denne svulsttypen. Evidensnivået er L5.

**For å gå videre kreves følgende:**
